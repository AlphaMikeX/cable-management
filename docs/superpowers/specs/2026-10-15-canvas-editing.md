# Canvas editing, version 0.3

User requirements: right sidebar contains only draggable icons for every port type; remove properties, bottom port list and tree view. Canvas is the working surface. Context menu rotates ports to an entered absolute angle and connects ports to existing mapped devices. Labels contain only equipment text or connected device name, otherwise exactly `not connected`. Drag labels independently with leaders anchored to ports. Drag device edges/corners in Edit mode to resize the two dimensions in the current named side view. Linked ports navigate on double-click and highlight the peer in the left device list on hover. All interface text is English. Preserve fixed named camera views, existing projects, physical connector sizes, safe saving and undo. Publish source to existing GitHub repository and replace the single runtime executable in the designated Google Drive folder.
